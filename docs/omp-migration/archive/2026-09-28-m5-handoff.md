> **For agentic workers:** Выполняй этот план последовательно, с проверкой каждого результата. Текущее рабочее дерево dirty; сохраняй чужие изменения. Не делай commit/push/PR. После завершения верни работу независимому reviewer, не объявляй собственный отчёт приёмкой.

**Goal:** Из текущей source-matched сборки можно безопасно собрать локальный пакет без конфигураций/секретов/истории пользователя, проверить его CLI в отдельном fixture data-root и уменьшить физическое число test-файлов без потери сценариев.

**Architecture:** Явный package allowlist предшествует любому `npm pack`. Проверка читает pack manifest и запускает установленный локальный tarball только в созданных временных roots с `PROVIDER_DOCK_HOME`, `CODEX_HOME` и `CLAUDE_CONFIG_DIR`, не переопределяя `HOME`/`USERPROFILE`. Отдельно объединяются три родственных transcript test-файла с сохранением всех assertions. **Tech Stack:** Node >=20, npm offline, TypeScript, Vitest. **Spec:** этот файл и [главы 3, 5, 7 единого плана](../REMAINING_PLAN.md); предыдущие задания/ревью — в [архиве](2026-09-28-m4-r2-handoff.md).
