
&#x20;11\. Недоступные модели

Недоступные модели не нужно выносить в отдельный раздел.

Они должны находиться вместе с остальными моделями, но визуально выделяться красным.

Также рядом должен отображаться отсчёт или информация о том, сколько ещё такая модель будет храниться до полного исчезновения.

В остальном этот блок пока выглядит нормально.

## 12. Запуск агентов

Текущий блок «Запуск агентов» мне не нравится.

### Выбор папки

Выбор папки сейчас выглядит немного странно, но пока это можно оставить.

### Режим Auto

Нужно нормально реализовать автоматический выбор CLI в зависимости от выбранной модели.

Например:

- если я выбрал у какого-то провайдера **Claude Opus**, то в режиме Auto он должен запускаться через **Claude Code**;
- если выбрана **GPT-5.6**, то она должна запускаться через **Codex CLI**;
- если выбрана какая-то другая модель, система должна сама определять, через какой CLI её правильнее запускать.

То есть режим Auto должен учитывать выбранную модель и автоматически выбирать подходящий CLI.

### Проблема с запуском

Сейчас, когда я нажимаю «Запустить агента», сам процесс запускается, но окно CLI / PowerShell не открывается.

Нужно разобраться, почему процесс есть, а окно PowerShell не появляется, и исправить это.

### Доступность запуска агента

Запуск агента не должен существовать только как отдельный большой блок.

Нужно сделать так, чтобы функция запуска агента была доступна почти из любого нужного места интерфейса, чтобы я мог быстро открыть её и запустить агента.

## 16. Совместимость с Codex CLI и Claude Code

Это одна из самых больших проблем.

Как я уже говорил раньше, была проблема, когда модель или провайдер не до конца отправляли ответ, либо происходили другие ошибки.

Также была проблема, когда модель начинала как будто реверсивно отвечать сама на себя и появлялись другие подобные проблемы.

Это нужно исправить **универсально для всех провайдеров**.

Нужно определить, какой формат API поддерживает каждый провайдер.

Например, некоторые провайдеры могут работать через:

- Chat Completions;
- Responses API;
- другие поддерживаемые форматы.

Нужно учитывать это при работе с Codex CLI и Claude Code, чтобы провайдеры нормально и стабильно работали через подходящий им формат.
